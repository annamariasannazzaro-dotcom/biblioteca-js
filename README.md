# LibraryAdmin - Gestore Biblioteca Responsivo

Un'applicazione web leggera e moderna per la gestione e registrazione di libri, sviluppata con **HTML5**, **JavaScript (ES6+)** e **Tailwind CSS**.

##  Funzionalità principali

- **Registrazione Libri**: Aggiunta di Titoli, Autori e Codici univoci.
- **Validazione Real-time**: Feedback immediato sui campi obbligatori e formattazione del codice.
- **Controllo Duplicati**: Sistema di prevenzione per evitare l'inserimento di libri con lo stesso codice.
- **Design Responsivo**: Interfaccia ottimizzata per Mobile, Tablet e Desktop grazie a Tailwind CSS.
- **Persistenza Dati**: Utilizzo del `localStorage` per mantenere i dati salvati anche dopo la chiusura del browser.
- **UI Moderna**: Tabella dinamica con stile zebra, effetti hover e gerarchia visiva dei contenuti.

## 🛠️ Tecnologie utilizzate

- **Tailwind CSS**: Per il layout responsivo e la stilizzazione avanzata (utilizzando utility classes).
- **JavaScript**: Manipolazione del DOM, gestione eventi e logica di validazione.
- **Google Fonts**: Font ottimizzati per la leggibilità (Inter/Satoshi).

##  Responsività
Il progetto segue l'approccio *Mobile-First*:
- **Mobile**: Layout verticale, input a tutta larghezza e tabella con scorrimento orizzontale.
- **Desktop**: Layout affiancato (label/input) e tabella estesa per una visualizzazione chiara.
